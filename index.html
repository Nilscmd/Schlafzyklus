Automatisch Wecker stellen

Damit ein Tipp auf eine Uhrzeit direkt einen Wecker in der Uhr-App anlegt, richte einmalig einen eigenen Kurzbefehl ein. Dauert etwa zwei Minuten.

  1. Öffne die Kurzbefehle-App und tippe auf + für einen neuen Kurzbefehl.
  2. Benenne ihn exakt Wecker stellen (oben im Kurzbefehl-Titel).
  3. Füge die Aktion „Text“ hinzu. Tippe „Heute um “ ein und füge danach die Variable Kurzbefehl-Eingabe ein.
  4. Füge die Aktion „Datum“ hinzu und wähle als Quelle den Text aus Schritt 3.
  5. Füge die Aktion „Wecker erstellen“ hinzu und wähle als Zeit das Datum aus Schritt 4.
  6. Fertig – tippe oben rechts auf das Häkchen zum Speichern.

Ab jetzt öffnet ein Tipp auf eine Uhrzeit kurz die Kurzbefehle-App und legt den Wecker automatisch an.
